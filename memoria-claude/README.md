# Memoria de Claude Code (para la Mac)

Estos archivos son la "memoria" que Claude Code usaba en el PC Windows.
Cópialos a su sitio en la Mac para que Claude recuerde tus preferencias y el proyecto:

## CLAUDE.md (preferencias globales del usuario)
Cópialo a:  ~/.claude/CLAUDE.md
(o pégalo en la raíz del proyecto como CLAUDE.md para que sea solo de este proyecto)

Contiene: quién eres (Jowy / YOWIPROD), cómo comunicarte, rutas, herramientas.
OJO: las rutas son de Windows (C:\, E:\). En Mac habrá que adaptarlas.

## MEMORY.md (memoria auto del proyecto RainTube)
Es el índice de memoria del proyecto. En la Mac, Claude Code lo recrea en:
~/.claude/projects/<carpeta-del-proyecto>/memory/MEMORY.md
Como el nombre de la carpeta cambia por máquina, lo más simple es:
pegarle a Claude en la Mac el contenido de este archivo al empezar, o dejar
que él lo recree. Sirve de referencia del estado del proyecto.
